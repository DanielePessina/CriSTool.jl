Measurements and losses ​

CriSTool.Observable Type
julia
Observable(; time, mean, variance=nothing) -> Observable

A measured observable (concentration, d43, pH, ...) represented uniformly as a time series. A single final-state measurement is a one-element time series, not a different data shape.

variance = nothing represents an unreplicated measurement. A scalar variance is accepted as a convenience and expanded across all measured points.

The constructor enforces the measurement contract used by loaders, losses, bootstrap, and plotting:

  • time and mean are non-empty vectors of finite real values;

  • times are strictly increasing;

  • a supplied variance has one value per measurement and is finite and nonnegative.

CriSTool.CrystallisationExperiment Type
julia
CrystallisationExperiment(; observables, exp_id, conditions, metadata=(;))

A single crystallisation experiment: a typed NamedTuple of observables (e.g. (concentration = Observable(...), d43 = Observable(...))), an integer identifier, the RunConditions it was run under, and additional metadata. Conditions may refer to the experiment's own time-zero observations through FromObservation placeholders.

The NamedTuple shape keeps the container type-stable and Tables.jl compatible; additional observables (pH, mass, PSD, ...) are added as new fields, not new container types.

CriSTool.experiments_from_table Function
julia
experiments_from_table(table; id_col=:Exp_ID, observables, metadata_cols,
                       temperature_transform=identity, filters=NamedTuple(),
                       initial_crystals_cols=nothing)
    -> Vector{CrystallisationExperiment}

Normalize a tabular measurement source into typed experiments. Each observable is described by an ObservableColumns value, allowing a different time grid for every observable. Rows with missing mean or time values are omitted from that observable only. Source rows are grouped by id_col; each observable is sorted independently by its declared time column.

CriSTool.GaussianNLL Type
julia
GaussianNLL(; weighting = (;), variance_model = MeasuredVariance(), relative_variance_floor = 1e-12)

Gaussian negative log likelihood summed over every scored measurement.

Fields:

  • weighting: factor per observable, as a NamedTuple or dictionary keyed by observable name, or a vector in the prepared observable order. Unnamed observables get 1. Weights are resolved once when the loss is prepared.

  • variance_model::AbstractVarianceModel: variance policy (default: measured variance)

  • relative_variance_floor::Float64: dimensionless minimum variance fraction relative to the squared observable magnitude

source

CriSTool.loss Function
julia
loss(lf, setup::LossSetup, params)

Sum named observable objectives across experiments. MAE pools each observable's included points before averaging; likelihood sums their NLL contributions. Observable weights are those resolved from the loss the setup was prepared with. Unsuccessful numerical solves receive a penalty. Invalid inputs and user-code exceptions propagate to the caller.

source

Evaluate the selected-parameter objective; AD scalar types are preserved.
