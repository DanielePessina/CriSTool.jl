julia
OptimisationSpec(; bounds, algorithm, loss=GaussianNLL(), adtype=AutoForwardDiff(), searchoptions=(;))

Select kinetic parameters by named (lower, upper) bounds and choose how they are optimised. algorithm is a Metaheuristics algorithm or an Optimization.jl solver; adtype and searchoptions apply to Optimization.jl solvers only.

CriSTool.BayesianSpec Type
julia
BayesianSpec(; priors, sampler=nothing, n_samples=1000, n_chains=1, loss=GaussianNLL())

Select kinetic parameters by named univariate priors and sample their posterior with a Turing sampler (nothing means Turing.NUTS()). Fitting requires using Turing, which loads the CriSToolTuringExt extension. The likelihood uses supplied measurement variances; noise is never fitted.

CriSTool.prepare_fit Function
julia
prepare_fit(model, experiments, specification; solver=MoM(), mode=TransientMode(),
            problem_options=(;), observable_order=nothing, observable_projections=(;),
            algorithm=nothing, solve_options=(;), callback_factory=nothing,
            parallel=EnsembleSerial())

Resolve each experiment's conditions, validate noise, bounds or priors, and build reusable solve templates. Time-zero observations consumed by FromObservation conditions are not scored. mode = SteadyMode(...) relaxes each run to its MSMPR steady state and needs numeric conditions to relax from. algorithm, solve_options and callback_factory configure the ODE solves. parallel = EnsembleThreads() solves the experiments of every loss evaluation (and so every ForwardDiff gradient) on separate threads; scores are reduced in experiment order, so the result is bitwise identical to EnsembleSerial(), the default.

source
StatsAPI.fit Function
julia
fit(prepared_fit; parallel=prepared_fit.setup.parallel)

Optimise the selected kinetic parameters with the specification's algorithm. A scalar objective returns a FitResult; NSGA2 returns one FitResult per Pareto candidate. parallel = EnsembleThreads() evaluates a Metaheuristics population on threads, each task on a private copy of the solve templates; for Optimization.jl solvers it solves the experiments of each loss evaluation on threads instead. It takes effect for this call only.

source
julia
fit(bayesian_prepared; rng=default_rng(), parallel=bayesian_prepared.setup.parallel, kwargs...)

Sample the posterior with the specification's sampler and counts. With n_chains > 1, parallel = EnsembleThreads() runs the chains on threads (MCMCThreads); with one chain it solves the experiments inside each log-density evaluation on threads instead. Other keywords go to Turing.sample (e.g. progress). Requires using Turing.

source
julia
fit(abc_prepared; parallel=abc_prepared.setup.parallel)

Sample under the specification's discrepancy threshold. parallel = EnsembleThreads() evaluates particles on threads, each on a private copy of the solve templates; the experiments of one discrepancy run serially.

CriSTool.TransientMode Type

TransientMode()

Integrate each run from time zero and compare the trajectory with observations at their measured times. This is the default for prepare_fit and predict.

Relax each run to its MSMPR steady state with options and compare the steady values with every observation, regardless of observation time. Run conditions must be numeric. Callable kinetic laws need autonomous = true.

StatsAPI.predict Function
julia
predict(result; saveat=nothing, observables=nothing, parallel=EnsembleThreads())
predict(result, runs; saveat=nothing, observables=nothing, parallel=EnsembleThreads())

Propagate a fit or posterior through the same model, solver, mode and numerical options it was prepared with. Without runs, the fitted experiments are predicted at their observation times. runs may hold experiments (conditions resolved from their time-zero observations) or numeric RunConditions, which need saveat. A FitResult predicts its single fitted draw. By default (parallel = EnsembleThreads()) every (run, draw) pair is solved on threads, each task on a private copy of the prepared templates; EnsembleSerial() gives identical results on one thread.

source
julia
predict(model, runs, samples; solver, mode=TransientMode(), problem_options=(;),
        saveat=nothing, observables=nothing, algorithm=nothing, solve_options=(;),
        callback_factory=nothing, parallel=EnsembleThreads())

Propagate user-supplied joint kinetic draws. The solver is required so that a prediction never silently changes numerical method. algorithm, solve_options and callback_factory are the solve settings accepted by prepare_fit. Each draw is reused across all runs; noise is added only through measurement_samples.

CriSTool.measurement_samples Function
julia
measurement_samples(predictions, observable; noise, rng)

Add explicitly supplied independent additive noise draws to future measurements, without modifying physical predictions. noise is a callable (experiment_id, observable, time) -> Distribution, or a fixed distribution. The caller owns interpolation and noise assumptions. Failed samples remain NaN.
